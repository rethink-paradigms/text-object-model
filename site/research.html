The Converging Pattern

Across 60+ years of prior work — from Ted Nelson's Xanadu (1960) through Engelbart's Augment (1970s), Purple Numbers (2000s), W3C Web Annotation (2013), Obsidian block references (2020), and BendScript (2024) — a single converging architectural pattern emerges.

One pattern, discovered six times. Xanadu, Purple Numbers, SiSU, Hypothesis, Notion, and BendScript all converged on the same architecture: separate content from structure, assign stable identifiers to every node, use applicative overlays for everything else. The Text Runtime is the first system designed to combine all their lessons.

The Referential Document Model

Every system that solved this problem converged on: documents are lists of pointers to content objects with stable IDs — not character buffers.

  1. Content is used by reference, not by value. Documents are lists of pointers to content objects. Editing changes the list of pointers, never the content objects themselves. (Xanadu's content lists, Hollywood's EDL model)
  2. Stable IDs are assigned at parse time. Two kinds: HIDs (hierarchical, break on move) and NIDs (persistent, survive moves). The field converged on NIDs as primary. (Purple Numbers)
  3. Links/annotations are applicative overlays. They sit outside the content and reference UUIDs. Enables profuse, overlapping, multi-author annotations without coordination. (Xanadu, Hypothesis, W3C)
  4. Anchoring is never perfect — use strategies with fallbacks. Hypothesis's 4-strategy cascade is canonical: exact → position → context-fuzzy → exhaustive.
  5. Dual selectors for robustness. Store both precise (UUID+offset) and fuzzy (text quote+prefix/suffix) selectors. Reconcile at write time. (W3C, Semiont)
"We give any text (including newly-input text strings) a permanent address, and thereafter use that text by pointing to it. Thus text is used 'in place', accessible simultaneously to many possible applicative uses."
— Ted Nelson, Xanalogical Structure, 2000

Prior Art Timeline

1960–2000
Project Xanadu (Ted Nelson)
Permanent content addresses. Content lists. Applicative links. Transclusion as first-class operation. The foundational vision for structured text.
1970s
Augment / NLS (Doug Engelbart)
Statement-level addressing with stable identifiers. The precursor to Purple Numbers' HID/NID distinction.
2001–2005
Purple Numbers (Eugene Eric Kim)
HID vs NID analysis. First wiki with automated fine-grained addressability (PurpleWiki). Demonstrated NID persistence for dynamic documents.
2006–2025
SiSU / Spine (Ralph Amissah)
Parse lightweight markup → abstract object model → emit any format. Object citation numbers stable across formats and translations. SQLite FTS integration.
2013
Hypothesis Fuzzy Anchoring
The canonical 4-strategy cascading fallback for annotation re-anchoring. Production-validated across millions of web annotations.
2017
W3C Web Annotation Data Model
Standard selector vocabulary: TextPositionSelector, TextQuoteSelector, RangeSelector, FragmentSelector, refinedBy nesting. Every edge case covered.
2019+
W3C Scroll-to-Text Fragment
Text directive in URLs: :~:text=prefix-,startText,-,endText,suffix-. Fragment directive stripped from URL before page sees it.
2020–2025
Obsidian Block References
Most widely deployed block reference system. ^block-id + ![[Note#^id]] transclusion. Showed what works and where plain-text limits hit.
2024
BendScript
Graph-first document protocol. Blocks + edges + content-addressed IDs. 9 typed edge predicates. Span-level addressing. Round-trip verified.
2025
Semiont (The AI Alliance)
W3C-compliant annotation for AI-assisted markup. Write-time selector reconciliation. LLMs supply exact + prefix/suffix; system computes offsets.

Key Research Findings

The research surveyed 30+ sources across 6 sub-domains. Here is what each domain taught us:

Finding 1
Stable Node Identity
UUID-based identity is production-proven (Notion, Tiptap). CRDTs provide character-level permanence (Yjs). Content-hash identity self-verifies but breaks on edits. We chose UUID v7 per structural node.
Finding 2
Annotation Anchoring
W3C Web Annotation is the mature standard. Multi-selector anchoring (position + quote) is the only production-proven strategy for robustness. Store both. Try position first, fall back to quote.
Finding 3
Transclusion
Exists but is fragile — almost universally at document/section level, never paragraph. No mainstream tool has stable paragraph identifiers. A Text Runtime with UUID addresses enables the first truly stable transclusion system.
Finding 4
Text Provenance
C2PA handles cryptographic content provenance. Wire does epistemic provenance for AI retrieval. TROVE traces sentences to sources. All are about attribution, not addressing. The runtime provides the substrate they annotate.
Finding 5
Structural Parsing
mdast, Pandoc AST, ProseMirror — all parse text into trees, but none give stable IDs at paragraph/sentence level outside their context. The runtime bridges structural parsing with stable identity.
Finding 6
Collaborative Editing
The Yjs + ProseMirror ecosystem has solved character-level stable identity. Yjs CRDT gives permanent identity to every character position. The runtime layer adds block/sentence-level identity on top.
