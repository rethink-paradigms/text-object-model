Missing Experience Layers

The Agent Is the User

When this project was in its research phase, the framing was human-centric — "the human writes, the human reads, the runtime stays invisible." That is still true. The human surface stays clean. But the primary consumer of the runtime's structured representation is the agent.

Every annotation, every reference, every provenance chain, every transclusion — those interfaces exist for agents, not for humans. The agent reads text with §N sentence markers as its cursor. The agent annotates by sentence number. The agent declares where its output came from. The human never sees any of this.

This reframe changes what we need to build. The engine — parsing, UUID assignment, storage, projection — is built and tested. What's missing are the three agent experience layers: Discovery, Structured Read Brief, and Output Declaration.

The engine is built. 9,300 lines of Rust. 28 source files. SQLite + content store. Pandoc AST pipeline. §N agent cursor. W3C annotations. Typed transclusion edges. What remains is giving agents the interfaces they need to use it productively.
